# Phishing URL Detection

A machine learning project that detects whether a URL is legitimate or potentially malicious.

## Overview

This project explores machine learning techniques for detecting phishing URLs. It uses URL-based features and classification models to distinguish between legitimate and phishing websites.

## Models Used

* Logistic Regression
* Support Vector Machine (SVM)

## Technologies

* Python
* Scikit-learn
* Pandas
* NumPy
* Jupyter Notebook

## Results

The models were trained and evaluated using standard classification metrics such as accuracy and F1-score.

## Project Purpose

The goal of this project is to explore how machine learning can be applied to a practical cybersecurity problem and help identify potentially malicious URLs.
